# Word Frequency Counter

A beginner-friendly C++ program that reads text from a file, counts word occurrences, and displays the results alphabetically.

## Features
- Reads words from an input file
- Ignores punctuation and case differences
- Counts word frequency
- Displays results alphabetically using `std::map`
- Saves the results to an output file

## How to run
Compile the project with a C++ compiler, then run the generated executable.
